# cli-commentator

CLIの出力を別ウィンドウで実況するMVP。

## 概要

本リポジトリは、CLIをPTYで包んで起動し、ログをイベント化して実況テキストを配信するための起点です。MVPはローカルのルールベース実況から始め、後でLLMアダプタを差し替え可能にしていく想定です。
