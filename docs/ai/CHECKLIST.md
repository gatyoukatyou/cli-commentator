# AI Session & Report Checklist

このチェックリストは、AI運用時の引き継ぎ漏れを減らすための最小運用手順です。

## 1) Session終了チェック

- [ ] セッションログを保存した（`docs/ai/sessions/` 配下、git管理外）
- [ ] 機密情報（APIキー/個人情報/内部URL）を含んでいないことを確認した
- [ ] 当日行った変更を 3行以内で要約した
- [ ] 対応したIssue/PR番号を記録した
- [ ] 未完了タスクと次アクションを記録した
- [ ] ブロッカー（要権限/外部依存）を明記した

## 2) 教育レポート作成チェック

- [ ] 誰向けのレポートか（非エンジニア/開発者）を明記した
- [ ] 何が変わったか（Before/After）を平易に書いた
- [ ] なぜその変更が必要だったかを説明した
- [ ] 影響範囲（ユーザー/運用/CI）を書いた
- [ ] 実施したテストと結果を記載した
- [ ] 用語解説（専門語の短い説明）を含めた
- [ ] 次アクションを優先順位つきで記載した

## 3) 運用テンプレート（最小）

### Sessionメモ
