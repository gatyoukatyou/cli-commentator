## 4. 重要な発見・リスク

- **このMac miniの既定Nodeは自己完結型でないが、B案で解決済み**
  - `/opt/homebrew/bin/node` (v22.22.0)、`otool -L` の非システム依存が17件（libnode / libuv / openssl / icu4c など）
  - `pnpm ensure:desktop-sidecar` が PR #344 の判定で `[sidecar_node_not_portable]` 停止する
  - nvm・volta・`/usr/local/bin` に代替なし
  - 公式Node v20.20.2（darwin-arm64）を `~/.local/node-v20.20.2-darwin-arm64` へ導入。tarballは公式SHASUMSとチェックサム照合済みで、`otool -L` の非システム依存は0件
  - 既定PATHとシェル設定は変更していない。Homebrew Node v22.22.0と、その上で稼働中のn8n（PID 21490）は無変更
  - `PATH="$HOME/.local/node-v20.20.2-darwin-arm64/bin:$PATH" pnpm ensure:desktop-sidecar` が通過。manifestは `nodeVersion: v20.20.2`、`nodeBinary: binaries/node-aarch64-apple-darwin/node`
  - CIは`actions/setup-node`でNode 20を使うため、同梱ランタイムをCIと同じmajorへ揃えた
  - 既定Nodeを切り替えなかった理由は、n8nがグローバルnpm導入でHomebrew Node prefix（`/opt/homebrew/lib/node_modules`）に載っており、切り替えには再インストールと再起動が伴うため
- **`apps/server` の `test` スクリプトは素の `vitest`**
  - 端末から実行すると watch モードに入って終わらない。CIは非TTYなので露見しない
  - スクリプトや自動化から呼ぶときは `pnpm -C apps/server exec vitest run` を使うこと（PR #364 はこの方式）
- **Claude in Chrome 拡張は localhost:5173 でもタイムアウトする**
  - convivial.online と同じ症状。Web UI の実機描画確認は Playwright を使う
